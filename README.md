# Florence by NightingaleMD

**Your Care Team, Everywhere at Once**

Florence is an AI-powered care navigation platform that helps healthcare organizations reach every patient who needs them.

## Features

- **Toggle System**: Switch between Health Plan and Provider Organization views
- **Memory & Personality**: Florence remembers patient preferences and builds relationships
- **Convene**: End phone tag forever with instant patient connections
- **Clinical Data Intelligence**: Real-time data from ADT feeds, CCDA, HIE networks, labs, and pharmacy
- **HEDIS Measures at Scale**: Automated outreach for quality measures (W30, CIS, AMR, FUM)
- **Agentic Documentation**: Chrome extension for seamless EHR integration

## Key Metrics

- 65% Readmission Reduction
- 24/7 Patient Reach
- 20+ Languages Supported

## Technology

- Single-page HTML application
- Responsive design with CSS Grid
- Toggle-based content matrix for personalized views
- Error handling with graceful degradation

## Deployment

This website is deployed on Vercel for permanent hosting.
